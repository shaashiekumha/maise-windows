🗣️ Text-to-Speech Studio

Features 54+ voices across US, UK, German, French, Italian, Greek, Japanese, Brazilian Portuguese, and Chinese accents with adjustable speech speed.

🎙️ Speech-to-Text Dictation

Real-time microphone capture with live audio level visualization, Word-level partial transcription, and support for WAV file drag-and-drop.

⚡ Global Windows Hotkeys

Press Win + Alt + S anywhere in Windows to speak highlighted text, or hold Win + Alt + D for push-to-talk dictation.

🌐 OpenAI API Compatibility

Run locally on port 8033 to serve speech synthesis and transcription directly to third-party tools, local web apps, or browser extensions.

💻 Command Line & API Usage

# Synthesize text to speech aloud
dotnet run --project Maise.Cli/Maise.Cli.csproj -- tts "Hello world from Kokoro on Windows!" --play

# Transcribe a WAV audio file with Distil-Whisper
dotnet run --project Maise.Cli/Maise.Cli.csproj -- asr speech.wav

# Start the background OpenAI-compatible REST server
dotnet run --project Maise.Cli/Maise.Cli.csproj -- server --port 8033
